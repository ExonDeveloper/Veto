# Veto
Veto removes AI integration, Recall and bloats from Windows 11.

How to use:

1. Extract the downloaded .zip file
2. Double click on Run.bat
3. Accept the UAC permission by clicking on "Yes"
4. After a GUI opens, select what to remove
5. Then click on "Execute Veto"

Blocking: Sometimes Microsoft Defender SmartScreen blocks from running scripts that are downloaded from the internet. Just click "More info" and then "Run anyway"

Again sometimes a window pops up. Just click on "Run"

If the tool still don't opens, right click on AutoRun.ps1, "Properties" and check on "Unblock"
